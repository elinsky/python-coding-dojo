## Notes

### General
- Problems marked "(Premium)" require a LeetCode Premium subscription
- Some EPI problems don't have direct LeetCode equivalents but cover similar concepts
- The Hanota problem is from LeetCode's "Cracking the Coding Interview" (LCCI) collection

### Mapping Clarifications
- **8.01**: EPI asks for max peek (not pop), so Min Stack #155 is a closer match than Max Stack #716
- **6.02**: Base 7 #504 uses the same algorithm; EPI version is more general
- **14.03**: K largest = reverse of k smallest; use reverse inorder traversal
- **16.06**: EPI's 0/1 knapsack maps to Partition Equal Subset Sum #416 (subset sum variant)
- **16.12**: EPI asks for nondecreasing (≤), LC #300 is strictly increasing (<); same algorithm
- **11.05/11.04**: Both map to Sqrt(x) #69; 11.05 is real square root, 11.04 is integer
- **13.07/13.08**: Both interval problems map to variations of Merge Intervals #56

### Problems Without Direct Equivalents
- **10.03** (Sort k-sorted array): Common interview problem, no official LC number
- **11.09** (Missing IP address): Bit manipulation + external storage problem
- **13.05** (Smallest nonconstructible value): Popular on AlgoExpert, not on LC
- **13.10** (Team photo day): Sorting/greedy problem unique to EPI
- **10.06** (K largest in max-heap): Heap traversal problem unique to EPI
- **11.07** (Min and max simultaneously): Algorithm optimization problem
- **14.07** (a+b√2 integers): Mathematical enumeration problem
