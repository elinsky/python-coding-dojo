# Common Format Codes

**Q:** What are the common strftime/strptime format codes?

**A:** Key format codes:

| Code | Meaning | Example |
|------|---------|---------|
| %Y | 4-digit year | 2024 |
| %m | 2-digit month | 01 |
| %d | 2-digit day | 15 |
| %H | 24-hour hour | 14 |
| %M | Minute | 30 |
| %S | Second | 45 |
| %B | Month name | January |
| %A | Weekday name | Monday |
| %w | Weekday (0=Sun) | 1 |
