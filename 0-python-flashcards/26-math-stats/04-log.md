# Logarithms

**Q:** How do I compute logarithms?

**A:** Use math.log(), math.log10(), math.log2()

```python
import math

math.log(math.e)    # 1.0 (natural log, base e)
math.log(100, 10)   # 2.0 (log base 10)
math.log10(100)     # 2.0 (same, more accurate)
math.log2(8)        # 3.0 (log base 2)
```
