# BST Search Complexity

**Q:** What is the time complexity of BST search/insert/delete?

**A:** O(h) where h is height; O(log n) if balanced, O(n) if skewed

```python
# Best case (balanced): O(log n)
# Worst case (skewed): O(n)
# Library implementations (e.g., red-black trees): O(log n) guaranteed
```
