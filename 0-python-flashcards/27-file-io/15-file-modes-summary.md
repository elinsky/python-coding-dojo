# File Modes Summary

**Q:** What are all the file mode options?

**A:** Modes can be combined:

| Mode | Description |
|------|-------------|
| 'r' | Read (default) |
| 'w' | Write (truncates) |
| 'a' | Append |
| 'x' | Exclusive create |
| 'b' | Binary mode |
| 't' | Text mode (default) |
| '+' | Read and write |

Examples: 'rb', 'w+', 'ab', 'r+b'
