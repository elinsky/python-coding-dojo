# Math Constants

**Q:** What constants are available in math module?

**A:** pi, e, inf, nan, tau

```python
import math

math.pi     # 3.141592653589793
math.e      # 2.718281828459045
math.tau    # 6.283185... (2*pi)
math.inf    # positive infinity
-math.inf   # negative infinity
math.nan    # Not a Number
```
