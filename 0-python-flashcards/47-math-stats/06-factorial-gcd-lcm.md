# Factorial, GCD, LCM

**Q:** How do I compute factorial, GCD, and LCM?

**A:** Use math.factorial(), math.gcd(), math.lcm()

```python
import math

math.factorial(5)   # 120 (5!)

math.gcd(12, 18)    # 6
math.gcd(12, 18, 24)  # 6 (multiple args)

math.lcm(4, 6)      # 12
math.lcm(4, 6, 8)   # 24
```
