# DP Terminology

**Q:** What are the key DP terms to know?

**A:**
- **Memoization**: Top-down DP with caching (recursive)
- **Tabulation**: Bottom-up DP with table (iterative)
- **State**: The parameters that define a subproblem
- **Recurrence**: Relation expressing solution using subproblems
- **Optimal substructure**: Optimal solution contains optimal subsolutions
- **Overlapping subproblems**: Same subproblems solved multiple times
- **Base case**: Smallest subproblem(s) solved directly
- **Cache/Table**: Storage for subproblem solutions
