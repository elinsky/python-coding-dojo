# When to Use DP

**Q:** What are the signs that a problem needs DP?

**A:**
1. Problem asks for **optimal** (max/min) or **count** ways
2. Need to make **choices** at each step
3. Solution relates to solutions of **subproblems**
4. **Same subproblems** appear multiple times
5. Brute force recursion has exponential time

**Common DP problem types:**
- Optimization (min/max)
- Counting (number of ways)
- Decision (yes/no possible)
