# Regex Character Classes

**Q:** What are the common character class shortcuts?

**A:** Built-in character classes:

| Pattern | Matches |
|---------|---------|
| `\d` | digit [0-9] |
| `\D` | non-digit |
| `\w` | word char [a-zA-Z0-9_] |
| `\W` | non-word char |
| `\s` | whitespace |
| `\S` | non-whitespace |
| `.` | any char (except newline) |
