# Python BST Library

**Q:** Does Python have a built-in BST library?

**A:** No, but use sortedcontainers or bintrees modules

```python
# sortedcontainers (recommended)
from sortedcontainers import SortedDict, SortedList

# bintrees (for pedagogy in EPI book)
import bintrees
t = bintrees.RBTree()
```
